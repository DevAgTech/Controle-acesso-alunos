# Funcionalidades do Sistema

## Cadastro de alunos

Permite registrar as informações básicas dos alunos no sistema.

## Consulta de alunos

Permite consultar os alunos cadastrados.

## Alteração de informações

Permite atualizar os dados dos alunos quando necessário.

## Exclusão de alunos

Permite remover um aluno do cadastro.
