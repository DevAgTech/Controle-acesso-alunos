# Requisitos do Sistema

## Requisitos funcionais

- RF01: O sistema deve permitir cadastrar alunos.
- RF02: O sistema deve permitir consultar alunos.
- RF03: O sistema deve permitir alterar os dados dos alunos.
- RF04: O sistema deve permitir excluir alunos.
- - RF05: O sistema deve permitir identificar cada aluno por uma matrícula única.

## Requisitos não funcionais

- RNF01: O sistema deve possuir uma interface simples e organizada.
- RNF02: As informações devem ser mantidas de forma organizada.
- RNF03: O sistema deve permitir o controle das alterações realizadas no projeto.
