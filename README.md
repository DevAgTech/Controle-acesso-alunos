# Controle-acesso-alunos

## Objetivo

O Sistema de Controle de Alunos tem como objetivo facilitar o cadastro,
a consulta e o gerenciamento das informações dos alunos.

## Principais funcionalidades

- Cadastro de alunos;
- Consulta de alunos;
- Alteração de informações;
- Exclusão de alunos.
